## One-paragraph description
ChaiCoin is an experimental, transparent, community-run token project inspired by the universal ritual of the chai break. It is built with a fixed, non-inflatable supply, no owner-controlled pause or blacklist capability, and a reputation/governance layer ("Kadak Points," "Chai Panchayat") designed to reward genuine community participation rather than speculation. The project publishes its research, decisions, tokenomics, and source code openly and does not promise financial returns.
