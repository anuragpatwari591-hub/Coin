# Target Publications — Research Process (not a pre-filled list)

This file intentionally does not ship with a pre-populated list of named journalists, because the master brief prohibits fabricating media relationships and any list generated without live research would be guessed, not real. Before any outreach:

1. Identify publications that genuinely cover: Indian crypto/VDA policy, meme-token culture, small/independent Web3 projects, or developer-focused crypto security writing.
2. For each candidate publication, find the specific journalist/section that has actually published relevant pieces recently (via the publication's own site/byline archive).
3. Add verified entries to `PR/journalist-outreach/media-database.csv` only once confirmed real (real byline, real recent article, real public contact method).
4. Never invent a name, outlet, or "connection" to make the list look more complete.

This process itself is a task for whoever operates PR for the project once there is something real (a testnet deployment, at minimum) worth pitching.
