# "Chai Break" — Recurring Community Event Format

**Cadence:** Weekly (day/time to be fixed once the community hub is live and a real, available moderator can host it consistently — no cadence is announced until it can actually be kept).

**Format (45–60 min):**
1. Open with a project-status recap pulled directly from `PROJECT_STATUS.md` (whatever's true that week — including setbacks).
2. Open floor / AMA — any question, answered honestly, "I don't know yet" is an acceptable answer.
3. Spotlight one piece of community-created content (meme, art, quest completion) from the week.
4. Announce the next quest/contest theme.

**Ground rules:** same as `community/telegram/rules.md` — no promises of returns, no fabricated updates. If nothing meaningful happened that week, the recap says so.
