# Moderation Guidelines

## Principles
- Moderators are real community members, never bots pretending to be human.
- Every enforcement action is logged (channel, user, action, reason, moderator, timestamp) in a private mod-log.
- Escalation ladder: warning → temporary mute → temporary ban → permanent ban. Scams/phishing/impersonation skip straight to permanent ban.
- Appeals go through DM to any moderator; a second moderator reviews disputed bans.

## Explicit violations and default action
| Violation | Default action |
|---|---|
| Guaranteed-returns / price-prediction spam | Warning, then mute |
| Phishing link / impersonation of team | Instant permanent ban + public warning post (no personal data disclosed) |
| Harassment/hate speech | Instant temporary ban (7 days), permanent on repeat |
| Fabricated partnership/listing/endorsement claims | Message deleted, warning, correction posted if it already spread |
| Unlabeled parody presented as real news | Message edited/deleted, reminder of rule 5 |
| Spam/unrelated self-promo | Message deleted, warning |

## What moderators must never do
- Delete legitimate criticism of the project.
- Use mod tools to silence disagreement that doesn't violate a rule above.
- Take any action anonymously without a mod-log entry.
