# Discord Server Structure

## Categories & channels
- **Welcome** — #start-here (rules + onboarding), #introduce-yourself
- **The Tapri (general)** — #general-chat, #chai-break-voice (scheduled AMA voice channel)
- **Quests & Contests** — #quest-board (active quests + Kadak Point values), #meme-contests, #submissions
- **Governance** — #chai-panchayat (polls), #proposals
- **Dev & Transparency** — #announcements (team-only posting), #github-updates (webhook from this repo's releases/CHANGELOG), #treasury-log (links to public multisig transactions once it exists)
- **Support** — #help, #report-a-problem (scams, bugs, bad behavior)

## Roles (mirrors `community/telegram/roles.md`)
Newcomer → Member → Chai-wale (Contributor) → Creator → Moderator, same criteria as Telegram. Role sync between platforms is manual until/unless a disclosed bot handles it.

## Bots
Any bot used (welcome bot, role-assignment bot, GitHub webhook) is standard, off-the-shelf, and disclosed as a bot in its own nickname/status — never presented as a person, never used to simulate member activity or fake message volume.
