Roadmap

No dates are promised as guarantees — this is an experimental, small-team project. Full detail: ROADMAP.md.

Phase 0 — Foundation

Research, brand, tokenomics, and architecture (this repository). Mostly complete.

Phase 1 — Testnet

Deploy and verify the contract on Polygon Amoy testnet, test everything end-to-end with real (testnet) wallets, open the community hub, run real events with real participants.

Phase 2 — Mainnet Gate

Mainnet deployment requires every item below to be true, then explicit human approval — whichever comes later:

  • Technical: contract tested, security self-review (and audit if budget allows) done, frontend tested against testnet
  • Economic: tokenomics unchanged or changes documented, liquidity plan published, treasury multisig live
  • Legal: regulatory research re-checked, professional review gates cleared
  • Community: website and docs live, community hub actively and transparently moderated

Phase 3 — Post-launch

Only after Phase 2 approval: launch dashboard, weekly honest reports (what happened, why, what worked, what failed, what changes next), ongoing security monitoring.

Explicitly out of scope unless separately approved: any presale, paid advertising spend, custodial wallet/exchange feature, or guaranteed-returns claim, at any phase.
