What this is

ChaiCoin is an experimental community token project inspired by the chai break — the universal ritual of gathering, talking, and building trust over a cup of tea. It's built with a fixed, non-inflatable supply, no owner-controlled pause or blacklist, and a reputation & governance layer that rewards genuine participation instead of speculation.

We publish our research, decisions, tokenomics, and source code openly, before asking anyone to join anything. See Documentation for the full trail.

Why it's different

No hidden mechanisms

No mint function after deployment, no transfer tax, no pause switch, no blacklist. Verify it yourself in the contract.

Utility you earn, not buy

Kadak Points and Chai Panchayat governance polls reward participation — quests, contests, moderation — never token purchases. See Utility.

Radically honest

No price predictions, no guaranteed returns, no fabricated partnerships or users — ever. See our Risks page.

Where we are right now: pre-testnet-deployment. No mainnet token exists, no funds have been raised, and there is no exchange listing. See the Roadmap for what happens next and what has to be true before mainnet is even considered.
