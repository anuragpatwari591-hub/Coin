Utility

ChaiCoin's utility is a reputation and light-governance layer built on the "chai break" ritual — earned through participation, never purchased.

Kadak Points

Non-transferable reputation earned via quests, contests, and helpfulness. Not a token, not for sale. See the Community page for how points are earned.

Chai Panchayat

Informal, non-binding community polls where holders and contributors weigh in on decisions like contest themes and feature priorities. A lightweight on-chain vote is a documented future milestone, not a launch-day promise.

Chai Cups

Badge-style recognition for contribution milestones. If ever implemented as NFTs, this will be documented plainly with standard risk disclaimers — never marketed as an investment.

None of this utility requires purchasing CHAI to access — that's a deliberate choice so the project's value isn't dependent on artificial buy pressure.
